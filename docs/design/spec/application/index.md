# 应用设计

NextSWITCH 各应用子系统的详细设计文档，涵盖信令、媒体、路由、CTI、IM 等核心服务。

## 子系统列表

| 子系统 | 说明 |
|--------|------|
| [信令服务器](./signaling/) | SIP 代理/注册、WebSocket/WebRTC 信令、呼叫流程、CDR |
| [媒体服务器](./media/) | 音频处理管道、录音、会议、IVR、转码、ASR/TTS |
| [路由配置](./routing/) | 路由规则配置与数据模型（路由决策由信令服务器执行） |
| [CTI 服务](./cti/) | 坐席状态机、呼叫控制、ACD 分配、事件推送、REST API |
| [IM 服务](./im/) | 即时消息、全渠道接入、AI 集成、CTI 联动 |
